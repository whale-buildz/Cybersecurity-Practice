# Cybersecurity Practice Portfolio

A hands-on cybersecurity learning portfolio documenting my progress in networking, Linux, ethical hacking, and penetration testing through practical exercises and authorised lab environments.

The goal of this repository is to build practical cybersecurity skills, strengthen my understanding of security concepts, and maintain clear documentation of my learning journey.

## 🎯 Learning Objectives

- Understand networking fundamentals and common network services.
- Develop Linux command-line and system administration skills.
- Learn reconnaissance and service enumeration.
- Understand common security misconfigurations and their impact.
- Practise identifying and documenting security findings.
- Improve technical reporting and problem-solving skills.

## 🧪 Hack The Box: Starting Point

I use Hack The Box Starting Point machines as a controlled environment for practising penetration-testing concepts.

| Machine | Difficulty | Primary Learning Areas | Status |

## 🛠️ Tools and Technologies

Tools used or explored during my learning journey include:

- **Parrot OS / Kali Linux:** Linux distributions used for cybersecurity practice.
- **Nmap:** Network discovery and service enumeration.
- **Redis CLI:** Interacting with Redis during database enumeration.
- **Telnet:** Understanding remote terminal access and its security implications.
- **Git and GitHub:** Version control and documentation management.

## 📝 Documentation Approach

Each completed lab is documented using a consistent structure:

| File | Purpose |
|---|---|
| `reconnaissance.md` | Initial information gathering and scan results |
| `enumeration.md` | Investigation of discovered services |
| `findings.md` | Security observations, weaknesses, and potential impact |
| `lessons-learned.md` | Key takeaways and concepts learned |

Raw scan output may also be included where useful.

## 🔐 Responsible Learning

All practical exercises documented in this repository are conducted in authorised training environments, such as Hack The Box.

This repository is intended for educational purposes only. The techniques and tools discussed should only be used on systems where explicit permission has been granted.

Sensitive information, credentials, VPN configuration files, and lab flag values should not be published.

This repository will grow as I complete additional labs, learn new tools, and improve my understanding of cybersecurity.
